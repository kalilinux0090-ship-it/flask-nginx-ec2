# CLOUD--ak

Multi-Tier Flask Application with Nginx Reverse Proxy on AWS EC2

## Architecture

Browser
   ↓
Nginx (Port 80)
   ↓
Flask Application (Port 5000)

## Technologies Used

- AWS EC2
- Linux
- Python Flask
- Nginx
- Git/GitHub

## Features

- Flask backend deployment
- Nginx reverse proxy
- Public access through port 80
